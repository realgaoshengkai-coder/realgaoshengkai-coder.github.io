Codex Native · 3D Style Incubator

不是模仿一张图，而是提炼一套造型系统。

输入参考图、turntable、render 或 mesh；输出有证据、有边界、能生成新方案的 3D Style Genome 与下游 Skill。

生成 Codex 启动指令 →查看 GitHub 源码

从样本到可执行规则

证据、生成力和验证必须同时成立。

01 / EVIDENCE

先分清看到、听到和推断到的。

每条造型判断标记 observed、reported、inferred 或 unknown，并保留样本、视角与来源。

02 / GENOME

把形容词翻译成几何决策。

用轮廓、比例、体块、曲率、特征线、负空间和失败条件组织可执行的 Style Genome。

03 / VALIDATION

身份与原创性使用两道门。

通过 holdout、新对象、多视角、功能约束及 identity / novelty 盲测后再交付下游 Skill。
